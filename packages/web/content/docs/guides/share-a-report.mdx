---
title: Share a report
description: How to make a report public, how to take it back, and how long Urai keeps it.
---

Every report starts private. Only the run's owner can see it: the tab that ran it, or a browser that opened the run's private link, since those are the only places that hold the run's owner token. Nothing is public until you choose to share it.

## Share it

When a run finishes, "Share the report" sits at the top of the run page, in the column beside the report's title, under the cost ledger. On a phone it comes after the summary and the cost ledger. If the report is already public, it says "This report is public" instead, with "Show the public link" and "Unshare".

1. Press "Share the report".
2. Urai lists exactly what the public page will show, under "Sharing makes all of this public", and asks you to confirm. Press "Yes, make it public", or "Keep it private" to back out.
3. Urai makes the report public at `/r/<reportId>` and shows the full link, with "Copy" next to it and "Open the public page" below.
4. Send the link to whoever should see it.

The list is the whole public page, in the order it shows:

- The run's name and every setting, with its model
- The system prompt
- The shared data you added to every case, when you added any
- The answer schema
- Every case's input, up to its first 2,000 characters
- The expected answers
- Every setting's answers and the scores
- The setup check's findings, the token counts and the estimated cost

It never shows your SERV key or your private run link. Share only what you are happy to publish.

Only the run's owner token can share a report (C11). Someone who holds the report link cannot use it to share, unshare, or drive the run, and the report id reveals neither the run id nor the workload id (C9). Sharing twice is harmless.

## Take it back

Press "Unshare" on the run page. The report is private again, and the old link answers "Report not found" from then on (C30). The not-found page is the same one a mistyped or expired link gets, so a visitor cannot tell a report that was taken back from one that never existed.

Share again later and the same link comes back.

> Note: unsharing needs the run's owner token. It lives in the tab that ran the report and dies when that tab closes, so press "Copy private link" on the run page first and keep the link somewhere private. Opening it in any browser brings the run back. The page says "This report is public" while it is, and "Unshare" takes it down. Without the tab or the link, the report link stays live until the workload expires.

## Public views are rate limited

Each public report view does real work on the server, so views are limited per network address: 120 an hour. Past that, the page says "Too many report views from your network this hour." and the API answers 429 (C31). The limit counts guessed ids too, so no one can scan for reports quickly. The run page's own reads of its report count toward the same 120.

## How long Urai keeps it

Your workload, its runs, their results and the report are kept for 30 days from the day you saved the workload. A daily clean-up then deletes all of them together, and the report link answers "Report not found".

Demo runs are kept for 7 days. Our sample workloads, and the four sample reports linked from [Live proof](/docs/proof), do not expire.
